### Hi there 👋

I'm a Python backend engineer with **4+ years of experience** designing and shipping production-grade APIs and backend systems. For the last **2+ years** I've also been building GenAI solutions, including RAG pipelines and Agentic AI workflows. My core stack is **FastAPI, Django REST Framework, and Flask**, backed by PostgreSQL, MySQL, MongoDB, Redis, and vector databases.

I enjoy turning messy business requirements into clean, scalable systems, and I've worked across Finance, Insurance, Logistics, and Pharmaceuticals domains.

* 🚀 Building backend systems and handling.
